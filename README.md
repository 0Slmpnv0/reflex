# Reflex
Welcome to my first serious web project! The idea of the app is to provide you the platform to collect, store and analyse any info about your life

The app gives you a form editor, where you can add up to five things, that you can track, and then explore the correlation between them. After the form is created, every day you come to the app, fill the fields and send a report. After some time the amount of data will become big enough to analyse and have some important* insights!

_*or not so important. That's not my responsibility:)_

## Content 
Basically, the app contains just 4 pages, that you will often use:
 + main page - this page is made to navigate you between other 3. Im not creative or experienced enough to design something more elegant, so... why not?
 + Manage form page - page, where you change the form's fields. **Its not recommended to use this too often, because you basically make all the data, that was collected before pretty useless** *(thats how MVP works I guess. Maybe then there will be some fixes to improve this logic)*
 + Daily report page - you enter this page daily, fill the fields, that you have configured in manage form page
 + Insights - page, where you will analyse the data, that has been collected all along

*(Also there will a calendar page, where you will be able to see every report by itself, but its not necessairy yet. But will be coming soon when I will be done with some more important things)*
